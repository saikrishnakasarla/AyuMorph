About AyuMorph

Academic B.Tech Information Technology Capstone Project

Project Abstract

AyuMorph (Ayurvedic Plant Intelligence Portal) addresses the challenge of botanical species identification by integrating computer vision and transfer learning with authenticated relational data management. In traditional Ayurvedic practice and botany, distinguishing authentic medicinal herbs from morphologically similar wild foliage requires significant taxonomic expertise. AyuMorph bridges this knowledge gap by providing a responsive web portal where students, botanists, and researchers can submit plant photographs and receive deep learning classifications powered by a trained MobileNetV2 convolutional neural network, backed by documented botanical and traditional knowledge.

Deep Learning Model Pipeline

  • Base Architecture: MobileNetV2

    Pre-trained on ImageNet to leverage generalized visual features (edges, textures, venation patterns).

  • Inverted Residuals & Linear Bottlenecks

    Employs depthwise separable convolutions that drastically decrease parameter footprint while preserving gradient propagation.

  • Custom Classification Head

    GlobalAveragePooling2D → Dense(128, activation='relu') → Dropout(0.2) → Dense(1, activation='sigmoid').

  • Input Resolution & Normalization

    Expected dimensions 224×224×3 with MobileNetV2 normalization scaling pixel channels to [-1.0, 1.0].

Software Engineering Principles

  • Modular Django Architecture

    Strict separation of concerns into distinct apps: accounts, plants, and classifier.

  • Singleton In-Memory Predictor

    Models are loaded into memory once and reused across inference queries, avoiding costly disk reloads.

  • User Data Isolation

    Prediction histories and audit logs are scoped strictly to the authenticated user via foreign-key constraints.

  • Defensive Image Validation

    Client and server-side checks verify MIME-types, byte headers, dimensions, and image integrity via Pillow.
